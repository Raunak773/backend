# Experiment 6: Client-side scripts for form validation using JavaScript

## Aim
To validate form input on the client side using JavaScript before submission.

## Course Outcome
CO2

## Files
- `index.html`: form and validation script

## How to run
Open `index.html`, leave fields blank or invalid, and click Submit.

## Concepts covered
- Form `submit` event and `preventDefault()`
- Regular expressions
- Name, email, 10-digit phone and password strength checks
- Password confirmation match
- Showing inline error messages

## Expected output
Red error messages under invalid fields. When everything is valid, an alert says the form was submitted successfully.
