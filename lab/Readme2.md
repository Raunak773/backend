# My HTML Tags Page

A simple beginner-friendly webpage created to demonstrate common HTML tags and basic CSS styling.

## About the Project

This project contains examples of several common HTML elements organised into different sections. It is designed for learning and practising the fundamentals of HTML and CSS.

## Features

- Semantic HTML structure using `header`, `nav`, `main`, `section`, `article`, and `footer`
- Navigation links to different sections of the page
- Home and About sections
- Image with `figure` and `figcaption`
- HTML5 video element
- Contact form with:
  - Name input
  - Email input
  - City selection
  - Message textarea
  - Submit button
- Blog section with a progress element
- CSS styling for layout, colours, forms, tables, buttons, and sections
- Hover effects for navigation links and buttons
- Responsive page width using `max-width`

## Technologies Used

- HTML5
- CSS3

## Page Sections

### Home
Introduces the HTML demonstration webpage.

### About
Explains that the page demonstrates HTML elements such as text, lists, tables, forms, and media.

### Gallery
Demonstrates an image, figure caption, and HTML5 video.

### Contact
Contains a simple contact form for entering a name, email address, city, and message.

### Blog
Contains a sample learning-progress indicator and a short paragraph about learning web development.

## How to Run

1. Save the webpage code as `index.html`.
2. Open `index.html` in a web browser.
3. Use the navigation menu to move between sections.

No installation or additional dependencies are required.

## Note

Make sure the image and video `src` attributes contain direct media URLs rather than HTML anchor (`a`) elements. For example:

```html
<img src="https://upload.wikimedia.org/wikipedia/commons/4/41/Flag_of_India.svg" alt="Indian Flag">
```

This project is intended for HTML and CSS practice and can be expanded later with JavaScript for form validation or other interactive features.
