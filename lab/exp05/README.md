# Experiment 5: Programs to demonstrate JavaScript array, object and functions

## Aim
To demonstrate arrays, objects and functions in JavaScript.

## Course Outcome
CO2

## Files
- `index.html`: page that loads the script and shows output
- `script.js`: all the JavaScript programs

## How to run
Open `index.html` in a browser. Press F12 to see the console output as well.

## Concepts covered
- Arrays: `push`, `pop`, `unshift`, `sort`, `map`, `filter`, `reduce`
- Objects: properties, methods, `this`, `for...in`, JSON
- Functions: declaration, expression, arrow, closure, recursion

## Expected output
The array results, object contents, and the function results (including 5! = 120) printed on the page and in the console.
