# Experiment 8: Programs to demonstrate DOM and event handling

## Aim
To demonstrate DOM manipulation and event handling in JavaScript.

## Course Outcome
CO2

## Files
- `index.html`: page with buttons, input, list and box, plus script

## How to run
Open `index.html` in a browser and interact with the elements.

## Concepts covered
- Selecting elements (`getElementById`)
- Creating, appending and removing nodes
- Changing styles dynamically
- Events: `click`, `input`, `mouseover`, `mouseout`, `dblclick`, `keydown`
- Event delegation

## Expected output
Add and remove list items, change the heading colour, see live text echo, hover colour change, and the last key pressed shown.
