# Experiment 1: Web page with all possible elements of HTML5

## Aim
To create a web page that uses the major HTML5 elements: semantic, text, table, media, graphics and form elements.

## Course Outcome
CO2

## Files
- `index.html`: the complete page

## How to run
Open `index.html` in any browser (double-click it).

## Concepts covered
- Semantic tags: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Text, lists, definition list, table, `blockquote`, `pre`, `code`
- Media: `img`, `figure`, `audio`, `video`
- Graphics: `canvas`, `svg`
- Forms: HTML5 input types, `datalist`, `meter`, `progress`, `details`

## Expected output
A single page with headings, a table, a canvas rectangle, an SVG circle and a form. The audio and video players are empty unless you add `sound.mp3` and `video.mp4` to the folder. The image needs internet access.
