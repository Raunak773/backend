# Experiment 11: Create a website with HTML, CSS and JavaScript (implement Ajax)

## Aim
To build a small multi-file website using HTML, CSS and JavaScript that loads its data with AJAX.

## Course Outcome
CO2, CO3

## Files
- `index.html`: structure
- `style.css`: styling
- `script.js`: AJAX loading, search and cart counter
- `products.json`: product data

## How to run
Run `python3 -m http.server 8000` in this folder and open http://localhost:8000.

## Concepts covered
- Separating HTML, CSS and JS
- AJAX with `XMLHttpRequest` loading JSON
- Rendering data dynamically
- Live search filtering
- Responsive CSS Grid

## Expected output
A product grid loaded from JSON, a search box that filters it, and an add-to-cart counter in the footer.
