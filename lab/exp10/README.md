# Experiment 10: Programs to familiarize jQuery (2 programs)

## Aim
To familiarize with jQuery through two programs: effects and DOM manipulation, and a todo list with AJAX.

## Course Outcome
CO2

## Files
- `program1.html`: hide, show, slide, animate and class toggle
- `program2.html`: todo list and `$.getJSON` AJAX call

## How to run
Open either file in a browser. An internet connection is needed (jQuery CDN, and the user API in program 2).

## Concepts covered
- `$(document).ready`, selectors
- Effects: `hide`, `show`, `slideToggle`, `animate`, `fadeOut`
- `css`, `toggleClass`, `append`, `remove`
- Delegated events with `.on()`
- `$.getJSON`

## Expected output
Program 1: buttons control a teal box. Program 2: add and delete tasks, and load a list of users from an API.
