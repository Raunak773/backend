# Experiment 4: Responsive web page with Bootstrap

## Aim
To build a responsive web page using the Bootstrap framework.

## Course Outcome
CO2

## Files
- `index.html`: page using Bootstrap 5 from a CDN

## How to run
Open `index.html` in a browser. An internet connection is needed to load Bootstrap from the CDN.

## Concepts covered
- Bootstrap CDN setup
- Responsive navbar with a collapsing toggler
- Grid system (`row`, `col-12 col-md-4`)
- Cards, buttons, form controls, utility classes

## Expected output
A dark navbar, a hero section, three cards that stack on mobile, and a form.
