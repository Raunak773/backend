# Experiment 7: Programs to familiarise ES6 concepts

## Aim
To familiarise with the main features introduced in ECMAScript 2015 (ES6).

## Course Outcome
CO2

## Files
- `index.html`: loads the script as an ES module
- `script.js`: ES6 examples

## How to run
ES modules need a server. Run `python3 -m http.server 8000` in this folder, then open http://localhost:8000. You can also run `node script.js` for console-only output, though the DOM lines will fail.

## Concepts covered
- `let` / `const`, template literals, default parameters
- Arrow functions, destructuring, spread and rest
- Classes and inheritance
- `Map`, `Set`, generators and iterators
- Promises and `async`/`await`

## Expected output
Printed results for each concept, with an async message appearing after about 300 ms.
