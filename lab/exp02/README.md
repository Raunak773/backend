# Experiment 2: Web page with all types of Cascading Style Sheets

## Aim
To demonstrate inline, internal and external CSS in one web page.

## Course Outcome
CO2

## Files
- `index.html`: page with inline and internal styles
- `external.css`: external stylesheet

## How to run
Open `index.html` in a browser. Keep both files in the same folder.

## Concepts covered
- Inline CSS (`style` attribute)
- Internal CSS (`<style>` in `<head>`)
- External CSS (`<link rel="stylesheet">`)
- Selectors and cascading order

## Expected output
A red heading (inline), a green paragraph (internal) and a navy bordered paragraph (external).
