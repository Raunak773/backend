# Experiment 3: Responsive web page with HTML and CSS

## Aim
To create a responsive page that adapts to different screen sizes using only HTML and CSS.

## Course Outcome
CO2

## Files
- `index.html`: page with embedded CSS

## How to run
Open `index.html` and resize the browser window (or use DevTools device mode, Ctrl/Cmd+Shift+M).

## Concepts covered
- Viewport meta tag
- Flexbox navigation and CSS Grid layout
- Media queries (768px and 480px breakpoints)
- Fluid images (`max-width: 100%`)

## Expected output
Cards in 3 columns on desktop, 2 on tablet and 1 on mobile. The navigation stacks vertically on small screens.
